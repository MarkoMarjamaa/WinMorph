# WinMorph
Morphing program for Windows ( created 1995 so here mostly for archiving reasons)

I made this when I was studying computer science in Oulu University. T2 movie just had got out and I said to my friends about it's morphing effects "I could program that". Well this wasn't quite the same level special effects but learned a lot about c++ object oriented programming, Delaunay triangulation, Floyd-Steinberg dithering and bicubic interpolation. Even some assembly!
